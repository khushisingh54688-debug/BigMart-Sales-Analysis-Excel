# BigMart Sales Analysis Dashboard Using Microsoft Excel

## Project Overview

This project focuses on analyzing BigMart sales data using Microsoft Excel. I created an interactive dashboard to understand sales performance across product categories, outlet types, outlet sizes, and fat content.

## Tools & Skills Used

* Microsoft Excel
* Pivot Tables and Pivot Charts
* KPI Cards
* Data Analysis and Visualization
* Sales Reporting and Dashboard Design

## Key Performance Indicators (KPIs)

* **Total Sales:** ₹18,591,125.41
* **Average Sales:** ₹2,181.29
* **Total Products:** 8,523
* **Total Outlets:** 10

## Dashboard Features

* Sales by Product Category
* Sales by Outlet Type
* Sales by Outlet Location Tier
* Sales by Outlet Size
* Sales by Fat Content
* Sales Trend by Establishment Year
* KPI cards for key business metrics
* Pivot-based sales summaries

## Project Objective

The objective of this project is to transform raw sales data into meaningful business insights and make sales performance easier to understand through visual reporting.

## Key Learnings

* Improved my Excel dashboard-building skills.
* Practiced analyzing data using Pivot Tables and Charts.
* Learned to present business KPIs in a clear visual format.
* Developed practical skills in sales reporting and data visualization.
